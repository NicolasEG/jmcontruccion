# Gonza Sagania Ultra Premium Completa

Base editable en HTML, CSS y JS puro.

## Incluye
- Home
- Servicios
- Contacto
- Loader inicial
- Hero con imagen y zoom cinematográfico
- Header glassmorphism
- Menú hamburguesa responsive
- Partículas sutiles sin librería externa
- Animaciones al hacer scroll
- Contadores animados
- Cards con hover 3D
- Galería con lightbox fullscreen
- Timeline
- Testimonios con slider automático CSS
- CTA premium
- Botón WhatsApp flotante
- Footer profesional
- Responsive completo

## Dónde editar
- Textos: index.html, servicios.html, contacto.html
- Colores: assets/css/style.css en :root
- Efectos responsive: assets/css/responsive.css
- Funciones JS: assets/js/main.js

## Reemplazar imágenes
Las imágenes están cargadas con URLs externas en variables CSS:
style="--hero-img:url('...')"
style="--img:url('...')"

Podés cambiarlas por:
style="--hero-img:url('assets/img/hero-home.jpg')"
